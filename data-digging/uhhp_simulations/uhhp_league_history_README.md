# UHHP League History JSON Documentation

## Overview
This JSON file contains the complete history of the UHHP Fantasy Hockey League for three seasons (2022-2023, 2023-2024, 2024-2025).

## File Structure

```json
{
  "league_name": "UHHP Fantasy Hockey League",
  "seasons": {
    "2022-2023": { ... },
    "2023-2024": { ... },
    "2024-2025": { ... }
  }
}
```

## Season Structure

Each season contains:
- **13 teams** with complete action histories
- **~470-525 total actions** per season
- **312 weekly matchup results** (24-26 per team including playoffs)
- **160-213 transactions** (signings, trades, drops, activations)
- **Final rosters** for each team

## Team Structure

```json
{
  "gm": "Manager Name",
  "actions": [
    { action objects sorted chronologically }
  ],
  "final_roster": {
    "active": [ players ],
    "reserve": [ players ],
    "injured": [ players ],
    "totals": { salary info }
  }
}
```

## Action Types

### 1. Signing
```json
{
  "timestamp": "2022-10-08T10:40:00Z",
  "type": "signing",
  "player": "Jared McCann",
  "position": "W",
  "nhl_team": "SEA",
  "details": {
    "salary": 2,
    "years": 1
  }
}
```

### 2. Trade
```json
{
  "timestamp": "2022-10-31T14:34:00Z",
  "type": "trade",
  "description": "Full trade details..."
}
```

### 3. Drop
```json
{
  "timestamp": "2023-04-10T18:23:00Z",
  "type": "drop",
  "player": "Spencer Knight",
  "position": "G",
  "nhl_team": "CHI"
}
```

### 4. Weekly Result
```json
{
  "timestamp": "2022-10-07T00:00:00Z",
  "type": "weekly_result",
  "period": 1,
  "dates": "10/7/22 - 10/16/22",
  "opponent": "South Calgary Oilers",
  "result": "W",
  "score_for": 96.0,
  "score_against": 75.0,
  "record": {
    "wins": 1,
    "losses": 0,
    "ties": 0
  }
}
```

## Usage

### Python
```python
import json

with open('uhhp_league_history_full.json', 'r') as f:
    data = json.load(f)

# Get all actions for a specific team in a season
team_actions = data['seasons']['2022-2023']['teams']['3sheets Sports Entertainment']['actions']

# Filter by action type
signings = [a for a in team_actions if a['type'] == 'signing']
weekly_results = [a for a in team_actions if a['type'] == 'weekly_result']
```

### JavaScript
```javascript
const fs = require('fs');
const data = JSON.parse(fs.readFileSync('uhhp_league_history_full.json', 'utf8'));

// Get all teams in a season
const teams = Object.keys(data.seasons['2022-2023'].teams);

// Get a team's final roster
const roster = data.seasons['2022-2023'].teams['3sheets Sports Entertainment'].final_roster;
```
